16, from Brazil. I write Node/Bun/TypeScript stuff for Discord audio.

Most of my time goes into making Lavalink alternatives less painful to run and maintain.

### Projects

| Project | What it is |
|---------|------------|
| [NodeLink](https://github.com/PerformanC/NodeLink) | Lavalink alternative in pure Node.js. I help maintain it. |
| [AquaLink](https://github.com/ToddyTheNoobDud/AquaLink) | Client wrapper for Lavalink/NodeLink. Focused on stability and low overhead. |
| [Kenium](https://github.com/ToddyTheNoobDud/Kenium-Music) | Music bot I built for fun with Seyfert. |
| [Tooka](https://github.com/ToddyTheNoobDud/Tooka) | Standalone Discord audio sending node (personal experiment). |

### Stack

Node.js · Bun · TypeScript · pnpm

I mostly care about audio pipelines, voice connections, and not wasting CPU/RAM on music bots.

### Quick history

I started on a computer with 4GB DDR3, an i3-5005U and a 111GB "SSD". My first real upgrade was in 2025, so I used that setup for 5+ years. Because of that I always tried to get the lowest CPU/RAM usage out of everything I wrote. I still do that today because i really want anyone with a lower setup to run my stuff without much problems :)

I started making Discord bots in 2020/2021 and [opened my first GitHub repo in 2023](https://github.com/ToddyTheNoobDud/Instinct-Music-V3).

Right now the focus is real-time audio nodes that stay compatible with the Lavalink v4 API.
